Vynn is a self-improving AI workflow platform. Create multi-step LLM pipelines, backtest trading strategies using natural language ("Buy when RSI < 30, sell when RSI > 70"), run parameter sweeps across strategy variations, and optimize portfolio weights. ## Key Features (for feature lists)

1. **Natural Language Backtesting** — Describe strategies in plain English or structured JSON. Get Sharpe ratio, max drawdown, win rate, and benchmark comparison.
2. **Self-Improving Workflows** — AI analyzes your workflow's performance and suggests better prompts, models, and configurations.
3. **Parameter Sweep** — Test hundreds of strategy variations at once and rank by Sharpe ratio, total return, or max drawdown.
4. **Portfolio Optimization** — Max Sharpe, min variance, risk budget, or Black-Litterman optimization across any universe of assets.
5. **MCP Server** — 21 tools for Claude Code, Cursor, and any MCP-compatible AI coding assistant.
6. **Cron Scheduling** — Automate any workflow on a schedule with timezone support.
7. **Webhook Triggers** — Fire workflows from external services via inbound webhooks.
8. **Telegram Bot** — Create and run workflows from Telegram chat.
9. **BYOK** — Bring your own API keys for OpenAI, Anthropic, Google, Groq, DeepSeek.
10. **Prompt Optimization** — AI generates up to 5 prompt variants ranked by estimated improvement.
